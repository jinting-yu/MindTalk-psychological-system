# 大学生心理健康管理系统
> 毕业设计项目，后端 SpringBoot + SpringAI，前端 Vue3 + TypeScript

## ✨ 项目简介
面向高校大学生的心理健康服务平台，支持心理测评、AI心理咨询、情绪日记、紧急联系人、心理科普文章、咨询师聊天等功能，辅助学生疏导心理压力，同时方便管理人员查看测评数据、跟进心理高危学生。

## 🛠️ 技术栈
### 后端
- Spring Boot
- Spring AI
- MySQL
- Redis
- RAG知识库检索
- DeepSeek API

### 前端
- Vue3 + TypeScript
- Vue Router
- Pinia
- Axios
- Element Plus
